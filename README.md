# 🎓 Student Performance Analysis

A comprehensive Data Analytics project that explores student academic performance using Python. The project focuses on data cleaning, exploratory data analysis (EDA), visualization, and extracting meaningful insights to understand the factors influencing students' academic success.

---

## 📌 Project Overview

Student Performance Analysis is a data analytics project that examines students' exam scores and demographic information to identify patterns affecting academic performance.

The project uses Python libraries to clean, analyze, and visualize the dataset, helping educators and students understand the key factors contributing to better academic outcomes.

---

- 📊 Exploratory Data Analysis (EDA)
- 🧹 Data Cleaning & Preprocessing
- 📈 Data Visualization
- 📉 Correlation Analysis
- 🎯 Performance Comparison
- 📚 Subject-wise Score Analysis
- 👨‍🎓 Gender-wise Performance Analysis
- 🍱 Lunch Type Analysis
- 🎓 Parental Education Analysis

---

# 📌 Key Insights

- Students who completed the test preparation course generally scored higher.
- Reading and writing scores show a strong positive correlation.
- Students with standard lunch tend to perform better than those with free/reduced lunch.
- Higher parental education levels are associated with improved student performance.
- Female students generally perform better in reading and writing, while male students often score slightly higher in mathematics.

# 📦 Installation

## Clone the Repository

```bash
git clone https://github.com/sanjay-9948/Student-performance-analysis.git
```

Navigate to the project folder:

```bash
cd Student-performance-analysis
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the notebook and run all cells.
